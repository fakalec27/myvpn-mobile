# Участие

Изменение должно объяснять проблему, выбранное решение и проверку. Для логики импорта, policy и transport нужны регрессионные случаи; для интерфейса — проверка состояний и читаемости. Не добавляйте готовые подписки, токены, серверные ключи, реальные device identifiers или пользовательские логи.

Перед предложением изменений запустите JVM и соответствующие native проверки из README. Не подменяйте неподдержанный транспорт прямым соединением. Сохраняйте upstream copyright, GPL и собственный бренд MyVPN.
