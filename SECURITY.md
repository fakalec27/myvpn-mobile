# Безопасность

Не размещайте в публичном issue секреты подписки, ключи SSH, HWID, ключи подписи или сырые логи. Описание должно содержать версию, безопасные шаги воспроизведения и ожидаемое поведение. После появления GitHub-репозитория private vulnerability reporting будет включено отдельным действием автора; сейчас канал и сроки ответа не заявлены.

Подписка и профиль являются недоверенным входом. Пользователь определяет провайдера и собственный сервер. Перед публикацией каждого release проверяются source/binary contents, зависимости, signing identity и соответствие исходников. Эти проверки не являются гарантией отсутствия всех уязвимостей.
