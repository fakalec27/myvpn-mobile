# MyVPN Mobile

Бесплатный Android-клиент для управления сетевыми профилями, подписками и правилами маршрутизации. Без донатов. Пользователь добавляет собственную подписку или сервер; приложение не продаёт доступ и не содержит готовых учётных данных.

MyVPN — самостоятельный бренд форка Android-клиента и ядра SagerNet. Проект не связан с разработчиками upstream и не использует их название как название продукта. GPL-3.0-or-later распространяется на клиент и ядро; лицензии отдельных зависимостей сохраняются.

## Возможности

- Импорт ссылок, подписок и готовых профилей с явным результатом разбора. Поддержанные подключения можно добавить отдельно, неподдержанные цепочки не разбираются на потенциально неверные части.
- Auto и Manual, проверка доступности HTTPS, сортировка по задержке, стране и имени. Учитывается свежесть измерения; задержка не выдаётся за скорость передачи.
- Правила для приложения и домена, сохранение назначений при обновлении подписки. Более точное правило домена имеет приоритет.
- Собственный выход SSH с проверкой ожидаемого IP. Учётные данные задаёт пользователь.
- Диагностические события службы VPN с ограниченным сроком и объёмом хранения, экспорт через системный выбор файла. Журнал не сохраняет содержимое трафика, URL подписок или ключи.
- Обратная совместимость форматов подписки, зашифрованное локальное хранение параметров запроса, собственные настройки маршрутизации и интерфейс на Compose Material 3.

## Ограничения

SSH-выход переносит TCP. UDP и IPv6 для назначенного ему трафика не поддерживаются; приложения, которым нужен UDP, требуют другого выхода. При фактических SSH-назначениях управляемый VPN-профиль использует IPv4 целиком, включая прямые назначения. Непрерывность открытого TCP-сеанса при потере транспорта не гарантируется. Измерений энергопотребления и пользовательского SLA пока нет.

Auto допускает только узлы с явно указанной страной вне России; неизвестные и российские узлы доступны в Manual. Если подходящих узлов нет, Auto не переводит назначенный ему трафик напрямую. Страна — метаданные провайдера, а не обещание геолокации фактического выхода. Фильтры списка не меняют Auto.

Публичная редакция отключает встроенный OTA до открытия сетевого соединения. У неё нет рабочего канала обновлений, ключа проверки или сертификата семейной подписи. Debug-приложение имеет отдельный идентификатор и стандартную debug-подпись; release без предоставленного keystore остаётся неподписанным. Сборка не требует подписки, телефона, VPS или частного сервера.

## Сборка

Windows: PowerShell 7, JDK 17, Go 1.26.8, Android SDK 37.1, build tools соответствующей платформы и NDK 28.0.13004108. Gradle wrapper фиксирует Gradle; версии Android/Kotlin-плагинов и зависимостей находятся в исходниках.

```powershell
$env:JAVA_HOME = 'C:/path/to/jdk-17'
$env:ANDROID_HOME = 'C:/path/to/Android/Sdk'
./build.ps1 -Native
```

Команда устанавливает pinned gomobile/gobind в локальную `.build/go`, собирает ARM64 native libraries из включённых исходников, запускает JVM tests и собирает debug APK. Для x86_64 используйте `-Architecture amd64`: скрипт согласованно задаёт ABI native сборки, Gradle split и UpdateTrust.

Повторный Android прогон после сборки native: `./build.ps1`. На Windows лучше использовать ASCII-путь checkout: AGP/AIDL могут некорректно обрабатывать кириллицу. Выходные AAR/APK, Gradle cache и локальные ключи не входят в Git.

```powershell
go test -C core-build-transport15 -tags 'with_awg,with_xhttp,with_utls,with_clash_api' ./protocol/group ./protocol/ssh ./common/urltest ./experimental/cachefile
```

## Как ведётся разработка

Публичные версии выпускаются проверенными снимками исходников. Рабочая история не заменяется придуманными PR или релизами. Для каждого следующего выпуска планируются review, CI, проверка ABI/версии/хэша native библиотеки и соответствующий source archive. Даты и результаты релизов появятся после фактической публикации.

Локальный кандидат ещё не опубликован. Публикация в отдельном репозитории и первый release требуют решения автора. О правилах участия и сообщениях об уязвимостях: [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md).
